## Objetivo de la práctica: 
Configurar el entorno de trabajo instalando el lenguaje Haskell mediante GHCup, instalar Git de forma local y crear un repositorio en GitHub para gestionar los trabajos y proyectos de la asignatura.   

## Tiempo requerido en realizar la práctica completa: 
Aproximadamente 2 horas.

## Comentarios y problemas a los que te enfrentaste en la instalación con su respectiva solución: 
Al utilizar Linux Mint, el proceso es similar al de Debian Linux. El principal inconveniente técnico fue que la terminal no reconozca el comando ghc tras la instalación. La solución fue actualizar el PATH ejecutando export PATH="$HOME/.ghcup/bin:$PATH" y cerrando y abriendo la terminal.
